# Metaverse (Unity 6 + Netcode for GameObjects)

멀티플레이 3D 공간. 아바타로 돌아다니고, 서로 보이고, 채팅한다.
마을에는 상점 NPC·모루·모닥불·퀘스트 게시판, 워프패드 너머에는 몬스터 사냥터·보스 던전·결투 아레나가 있다.
사냥 → 골드·경험치 → 레벨업, 채집 → 제작·요리, 퀘스트·거래·이모트까지. 진행 상황은 서버에 저장된다.

## RPG 규칙

| 항목               | 값                                                                                   |
| ------------------ | ------------------------------------------------------------------------------------ |
| 최대 HP            | `100 + (레벨-1) * 20`                                                                |
| 공격력             | `8 + (레벨-1) * 3 + 무기Lv * 4`                                                      |
| 방어력             | `8 + (레벨-1) * 2 + 방어구Lv * 3`                                                    |
| 레벨업 필요 경험치 | `40 + (레벨-1) * 30` (레벨업 시 HP 완충)                                             |
| 몬스터 레벨        | 접속한 플레이어 평균 레벨 기준. Slime `+0` / Goblin `+1` / Orc `+2` (최소 1)         |
| 몬스터 HP          | `20 + 몬스터Lv * 26` (Lv1 46, Lv5 150, Lv10 280)                                     |
| 처치 보상          | 경험치 `12 + 몬스터Lv*8`, 골드 `4 + 몬스터Lv*3`                                      |
| 몬스터 공격력      | `6 + 몬스터Lv*4` (1.6초 쿨다운, 인식 12m, 리쉬 26m). 방어력(+2/레벨)보다 빨리 자란다 |
| 무기 강화          | `60 * (다음Lv)` G → 공격력 +4                                                        |
| 방어구 강화        | `50 * (다음Lv)` G → 방어력 +3                                                        |
| 받는 피해          | `몬스터 공격력 - 방어력` (최소 1). 방어구로 0까지 줄일 수는 없다                     |
| 사망               | HP 0 → 마을 스폰 지점으로 복귀, HP 완충 (페널티 없음)                                |
| 마을 자동 회복     | 마을 안(원점 기준 ±32)에 있으면 1초마다 최대 HP의 4% 회복. 사냥터에선 안 됨          |

전투·보상·구매 판정은 전부 서버에서만 계산한다. 클라이언트는 "공격했다"는 요청만 보낸다.

몬스터 레벨은 고정이 아니다. 스폰할 때, 부활할 때(6초), 그리고 주변에 플레이어가 없어 한가할 때 다시 계산한다.
전투 중이거나 피가 깎인 몬스터는 건드리지 않으므로 싸우는 도중에 갑자기 강해지지 않는다.

레벨이 오르면 몬스터도 **눈에 보이게** 달라진다: 몸집이 레벨당 4%씩 커지고(최대 1.8배), 색이 점점 짙어진다.
배치도 난이도 순이다 — Slime은 사냥터 안쪽, Goblin은 중간, Orc는 바깥 가장자리.

## 던전 (보스)

마을 워프패드(`Lv.5+` 제한) → 던전. 사냥터와 같은 방식의 **공유 구역**이라 파티별 인스턴스는 없다 — 같은 보스를 다 같이 친다.

| 항목      | 값                                                                |
| --------- | ----------------------------------------------------------------- |
| 입장      | 마을 워프패드, 레벨 5 이상                                        |
| 구조      | 통로(가드 6마리, 플레이어 레벨 **+3**) → 보스 방                  |
| 보스      | `Ogre Lord`, 플레이어 평균 레벨 **+5**, HP **8배**, 몸집 2.4배    |
| 보스 공격 | 일반 공격 + **7초마다 반경 6m 강타(피해 2배)** — 뭉쳐 있으면 전멸 |
| 보상      | 경험치·골드 **6배**, 딜을 넣은 **전원**에게 지급                  |
| 부활      | 처치 후 3분                                                       |
| 처치 알림 | 전체 채팅에 공지                                                  |

보상이 막타가 아니라 **기여자 전원**에게 가므로 남을 도와도 손해가 없다.
천장은 일부러 없다 — 카메라가 실내 충돌을 처리하지 않는다.

## 외형 규칙

같은 모양이 두 가지 뜻을 갖지 않도록 실루엣을 나눴다.

| 대상            | 표현                                                                                                          |
| --------------- | ------------------------------------------------------------------------------------------------------------- |
| 마을 건물       | 벽 + 처마가 나온 박공지붕 + 모서리 기둥 + 문·창문. 상자 하나가 아니다                                         |
| 마을 기념비     | 계단식 받침 + 오벨리스크 + 회전한 큐브 첨탑                                                                   |
| 사냥터 지형지물 | 전부 곡면 — 둥근 바위, 잎 없는 고사목, 풀 무더기. 각진 건 하나도 없다                                         |
| **광맥**        | 어두운 돌덩이에 **밝은 청록 수정**이 비스듬히 박혀 있다. 반짝이는 건 세상에 이것뿐                            |
| 약초            | 초록 덤불 + 노란 꽃 3송이                                                                                     |
| 나무            | 기둥 + 뭉친 잎 3덩이                                                                                          |
| 워프 게이트     | 돌기둥 2개 + 상인방 + **행선지 색 포탈 판** + 떠 있는 룬. 주황=사냥터, 보라=던전, 청록=마을                   |
| 몬스터          | 슬라임=다리 없는 덩어리 / 고블린=뾰족귀 소형 인간형 + 발톱 / 오크=어깨 넓은 거구 + 엄니 / 오우거=뿔 달린 보스 |

몬스터 몸체는 프리팹 하나에 4개가 다 들어 있고 `Shape`(서버 소유)로 하나만 켠다 — 네트워크 프리팹은 여전히 1개다.
눈·엄니·뿔·발톱은 이름으로 걸러서 레벨 색조에 물들지 않는다.

## 아레나 (결투, `z = 120`)

마을 워프패드(붉은 게이트) → 아레나. 낮은 담으로 둘러싼 링, 붉은/푸른 시작 마크, 관중석, 횃불이 있다.

| 항목 | 값 |
| --- | --- |
| 신청 | 링 **안에서** `G` — 가장 가까운(12m 이내) 플레이어에게 |
| 수락 | `H` (15초 안에) |
| 시작 | 양쪽을 반대편 마크로 옮기고 **HP 완충** → 3초 카운트다운 |
| 피해 | `공격력 - 방어력`(최소 1). 좌클릭·사거리·각도는 사냥과 동일 |
| 승패 | HP가 **1**이 되면 종료. 죽지 않으니 페널티도 없다 |
| 그 외 종료 | 링 밖으로 나가면 몰수패, 90초 초과 시 무승부, 접속 종료 시 상대 승 |
| 기록 | 승/패가 스탯 HUD와 세이브에 남고, 결과는 전체 채팅 공지 |

**PvP는 아레나 밖에서 불가능하다.** 서버가 "지금 진행 중인 매치의 상대"만 피해 대상으로 인정하기 때문에, 마을이나 사냥터에서는 서로 때릴 수 없다. 카운트다운 중에도 매치가 `Live`가 아니라 피해가 들어가지 않는다.

거래와 같은 세션 구조다 — 서버가 매치 목록을 쥐고, 클라이언트는 신청·수락만 보내고 화면만 그린다.

## 생활 컨텐츠

### 채집

| 노드 | 위치                  | 획득             | 쿨타임 |
| ---- | --------------------- | ---------------- | ------ |
| 광석 | 사냥터 4곳 + 마을 2곳 | Ore 1, 경험치 5  | 8초    |
| 약초 | 마을 5곳              | Herb 2, 경험치 3 | 8초    |
| 나무 | 마을 4곳              | Wood 2, 경험치 3 | 8초    |

`E`로 채집. 서버가 거리를 다시 검사하고, 캔 노드는 안 보이게 되며 쿨타임 뒤 되살아난다.

### 제작 (모루)

| 레시피          | 재료          | 효과                  |
| --------------- | ------------- | --------------------- |
| Sharpen weapon  | Ore 3, Wood 1 | 무기 +1 (공격력 +4)   |
| Reinforce armor | Ore 2, Wood 2 | 방어구 +1 (방어력 +3) |

골드로 사는 상점 강화와 같은 결과다 — 골드가 없으면 발로 뛰면 된다.

### 요리 (모닥불)

| 요리            | 재료                  | 버프               |
| --------------- | --------------------- | ------------------ |
| Herb stew       | Herb 2, Wood 1        | 공격력 +6, 3분     |
| Iron broth      | Ore 1, Herb 1, Wood 1 | 방어력 +6, 3분     |
| Traveller's tea | Herb 2                | 이동속도 +40%, 2분 |

버프는 한 번에 하나. 새로 먹으면 교체된다. 남은 시간은 서버 시계로 계산해서 매 초 동기화하지 않는다.

### 퀘스트 (게시판)

한 번에 하나 수주. 몬스터 처치·채집 이벤트에서 자동 진행되고, 게시판에서 보상을 받는다.
목록: 몬스터 5마리(40G/30exp) · 광석 8개 · 약초 8개 · 나무 6개 · 몬스터 12마리(90G/70exp).

### 거래

가까운 플레이어에게 `T` → 상대가 `Y`로 수락 → 골드·재료 수량을 서로 조정 → 양쪽 Confirm.
제안이 바뀌면 확인이 초기화되고, 12m 이상 멀어지거나 접속이 끊기면 자동 취소된다.
교환은 서버가 양쪽 잔고를 확인한 뒤 **한 번에** 처리한다.

### 이모트

`Z` 인사, `X` 춤, `C` 앉기. 같은 키를 다시 누르거나 움직이면 풀린다.

### 저장

서버가 15초마다, 그리고 종료 시 `metaverse-save.json`에 기록한다 (`Application.persistentDataPath`).
키는 **닉네임**이라 같은 닉네임으로 접속하면 레벨·골드·장비·재료·퀘스트가 이어진다.
LAN·소규모용 신원 확인이고 보안 장치는 아니다.

## 모션

| 모션        | 방식                                                                       |
| ----------- | -------------------------------------------------------------------------- |
| 검 장착     | 오른팔 피벗 밑에 붙은 손잡이+가드+칼날 (별도 본 없음, 팔 회전 따라감)      |
| 공격 스윙   | 0.35초 — 머리 위로 들었다가(-150°) 앞으로 내리침(-40°). 걷기 스윙을 덮어씀 |
| 피격        | HP 감소를 모두가 감지 → 몸통 22° 뒤로 젖혔다 복귀 (0.3초)                  |
| 몬스터 피격 | 흰색 플래시 + 눌렸다 펴지는 스쿼시 (0.25초)                                |
| 몬스터 공격 | 몸통 전체가 앞으로 찌르며 숙임 (0.35초). 팔 피벗이 없어 몸으로 표현        |
| 보스 강타   | 뒤로 젖혔다 내리찍음 (0.6초) + 바닥에 **실제 사거리 6m짜리 링**이 퍼진다    |

공격 모션은 소유자가 즉시 로컬 재생하고, 서버가 나머지에게 `SendTo.NotOwner`로 알린다.
몬스터는 공격 판정 자체가 서버에서만 나므로 `SendTo.Everyone`으로 모션을 알린다.
피격 모션은 HP가 이미 복제되므로 RPC 없이 `OnValueChanged`만으로 처리한다.

## 실행

1. Unity 에디터에서 `Assets/Metaverse/Scenes/Metaverse.unity` 열기
2. Play → 왼쪽 위 패널에서 닉네임 입력 → **Host (play + serve)**
3. 다른 사람은 같은 씬에서 서버 IP 입력 → **Join as client**

기본 포트 `7777` (UDP). 같은 공유기 안이면 호스트의 내부 IP(`ipconfig`), 밖에서 붙으려면 7777 포트포워딩 필요.

## 조작

- `WASD` / 방향키 — 이동
- `Shift` — 달리기
- `Space` — 점프
- 마우스 좌클릭 — 공격 (사거리 2.6m, 앞쪽 120° 안, 0.6초 쿨다운)
- `E` — 워프패드 이동(던전은 Lv.5+) / 상점·모루·모닥불·게시판 열기 / 채집
- `T` — 근처 플레이어에게 거래 신청, `Y` — 수락
- `G` — 아레나에서 결투 신청, `H` — 수락
- `Z` / `X` / `C` — 인사 / 춤 / 앉기
- 마우스 우클릭 드래그 — 시점 회전, 휠 — 줌
- `Enter` — 채팅창 포커스, 다시 `Enter` — 전송

## 커맨드라인 자동 접속

빌드한 exe는 클릭 없이 바로 붙을 수 있다 (전용 서버·테스트용):

```
Metaverse.exe -mvhost -mvnick 호스트
Metaverse.exe -mvclient 192.168.0.10 -mvnick 손님
Metaverse.exe -batchmode -nographics -mvhost        # 화면 없는 전용 서버
```

`-mvport 7777`로 포트도 지정 가능.

## 한 PC에서 여러 명 테스트

- **방법 A (권장)**: `File > Build Settings > Build`로 exe 뽑고, 에디터에서 Host + exe 여러 개 Join
- **방법 B**: `Window > Multiplayer > Multiplayer Center`에서 Multiplayer Play Mode 패키지 설치 → 가상 플레이어 창으로 테스트

## 씬 다시 만들기

씬을 망가뜨렸으면 메뉴 `Tools > Metaverse > Build World Scene` 실행. 월드·프리팹·머티리얼을 덮어써서 새로 만든다.
**RPG 콘텐츠(상점 NPC·워프패드·사냥터·몬스터)는 이 메뉴를 한 번 실행해야 씬에 들어간다.**

월드 배치: 마을은 원점 기준 ±30, 사냥터 `x = 120`, 던전 `x = -120`, 아레나 `z = 120` 중심의 같은 크기 구역. 네 구역은 워프패드로만 오간다.
